# Emoji Şarj

Flutter Android MVP. Gerçek pil seviyesi, şarj durumu, dört emoji karakteri ve basit pompalama/ter silme durum animasyonu içerir.

## APK
GitHub Actions > Android APK > Run workflow. İş bitince `emoji-sarj-debug-apk` artifact dosyasını indirin.

Not: Bu ilk sürüm çizgi film animasyonu değil, emoji tabanlı prototiptir. Uygulama açıkken çalışır. Google Play için release imzalama ve AAB ayrıca hazırlanmalıdır.
